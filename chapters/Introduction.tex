Modern applications running on the Internet are increasingly distributed to enable scalability, improve service availability, and decrease user latency. In a distributed system, individual components can only coordinate via message passing over a network, making it naturally volatile and prone to partial failures \cite{Coulouris-DistributedSystems-2005}. This failure model and the asynchronous nature of communication networks, preventing a global notion of time, make many conceptually simple problems notoriously difficult. One is referred to as the \textit{consensus} problem \cite{Coulouris-DistributedSystems-2005, Fischer-DistributedConsensus-1985, Dwork-ConsensusPartialSynchrony-1988} and requires multiple processes to decide on the same value.

Research on this problem has come a long way since the original \textit{Paxos} algorithm for solving consensus \cite{Lamport-Paxos-2001} was designed. \textit{Fast Paxos}, for instance, introduced the \textit{fast-path}, eliminating a one-way delay under favorable conditions \cite{Lamport-FastPaxos-2006, Zhao-FastPaxos-2015}. In practice, these algorithms are extended to maintain a continuously growing total-order \textit{distributed log}, which enables the implementation of \gls{SMR} for processing deterministic operations on multiple nodes with guaranteed convergence to the same state \cite{Schneider-ReplicatedStateMachines-1990}. This is an important abstraction for applications like distributed databases \cite{Corbett-GoogleSpanner-2013, Taft-CockroachDB-2020, etcd-Docs} and coordination services \cite{Burrows-Chubby-2006, Hunt-Zookeeper-2010}.

While consensus-based distributed logs inherently provide strong safety guarantees, they can dominate end-to-end system performance regarding throughput and latency through their message complexity, particularly in geo-replicated deployments \cite{Stathakopoulou-RSMScalability-2022, Ryabinin-SwiftPaxos-2024}. As a result, a significant portion of current research focuses on reducing the overhead of log replication by using versions of the optimistic fast paths originally devised for Fast Paxos \cite{Moraru-Epaxos-2013, Park-Curp-2019, Geng-NezhaConsensus-2022}.

Fast-path algorithms are, however, inherently optimistic. They assume a lack of concurrent client proposals to bypass a communication step. This optimistic assumption fails in the event of a collision, which occurs when multiple clients simultaneously propose conflicting values for the same log index. Resolving these collisions requires expensive, multi-round recovery mechanisms to maintain safety invariants. Under heavy contention, this recovery causes performance to degrade severely, rendering the system slower than a baseline, conservative protocol \cite{Junqueira-ClassicVsFastPaxos-2007}. To circumvent these collision penalties, much of the current research on \gls{SMR} departs from a single, totally ordered replicated log in favor of partially ordered or command-ordering mechanisms \cite{Ryabinin-SwiftPaxos-2024, Moraru-Epaxos-2013, Park-Curp-2019}. While this approach minimizes recovery costs, it forces the consensus layer to evaluate possibly complex application-level semantics to identify commuting commands. Furthermore, many applications may simply require strict total ordering.

An alternative, underexplored approach is to retain the totally ordered log as the core abstraction while regulating access to the fast path based on current conditions \cite{Junqueira-ClassicVsFastPaxos-2007}. A system could gate fast-path attempts using a heuristic or predictive model, falling back to a conservative execution path when the risk of a conflict is high. Such a regulator must make decisions under uncertainty: allowing too many collisions increases overhead, while being overly conservative sacrifices potential latency improvements. \textit{Conformal methods} \cite{Shafer-ConformalPrediction-2008, Angelopoulus-ConformalPrediction-2023, Angelopoulus-ConformalRiskControl-2025} have emerged as a statistical framework for augmenting arbitrary predictive mechanisms with strict mathematical guarantees. While operating without assumptions about the underlying data distribution, conformal approaches calibrate decision thresholds based on observed outcomes and can regulate decision risk.

This thesis explores the usability of a hybrid consensus protocol that integrates decentralized path selection with conformal methods. In this \textit{Conformal Consensus} design, individual followers independently evaluate local network conditions to dynamically decide between using an optimistic fast path or the conservative route, while a conformal wrapper attempts to bound fast-path error rates.

\section{Research Questions}
\label{sec:research_questions}
Given the goal of bridging statistical risk control with distributed consensus, this work is guided by two research questions:

\begin{enumerate}[label=\textbf{\Roman*.}]
    \item \textit{How can conformal methods be applied to regulate fast-path attempts in a replicated log abstraction while bounding the error rate?}
    \item \textit{To what extent does this approach reduce end-to-end latency compared to traditional, non-adaptive consensus baselines within distributed environments?}
\end{enumerate}


\section{Challenges}
To answer these questions, the work must overcome several challenges, which define the primary objectives and contributions of this study:
\begin{enumerate}
    \item Exploring the design of a "hybrid" consensus protocol for replicated logs where different nodes can independently and dynamically switch between fast and regular modes.
    \item Identifying which locally observable metrics have predictive capabilities of fast-path success and designing a practical heuristic.
    \item Employing an online calibration method that can track a target rate of fast path mistakes.
    \item Demonstrating through geo-replicated deployment if the adaptive methodology can improve end-to-end latency compared to baselines.
    \item Determining the impact of risk regulation on the computational cost to prevent the regulator from becoming a performance bottleneck.
\end{enumerate}

The application of conformal risk control to the domain of distributed consensus is, to our knowledge, novel. The findings could be of interest to distributed systems researchers who deal with the volatility of optimistic protocols in geo-replicated environments. 


\section{Research Methodology}
We outline the research methodology following the structure suggested by Håkansson \cite{Hakansson-ResearchMethods-2013}. Accordingly, this thesis uses a quantitative research methodology, a positivist research paradigm, and a deductive research approach. This is appropriate because the research aims to answer research questions about the effect of fast-path regulation on system performance using objectively measurable variables such as latency and fast-path error rate. The study assumes that system behavior can be observed, measured, and analyzed statistically and that cause–effect relationships between protocol behavior and performance can be established through controlled experiments.

The primary research methods adopted in this thesis are experimental and empirical. The study is experimental because it involves implementing a regulator, manipulating system conditions, and measuring the resulting effects on performance under controlled conditions. It is empirical because the conclusions are based on observed data collected from simulations and experiments. To ensure research quality, the work addresses replicability through controlled experimental setups and publicly available artifacts. \footnote{The library artifacts and reproducible experiment scripts are openly available under: \url{https://github.com/kilianp14/conformal-consensus}}

\section{Delimitations}
This thesis is highly exploratory, as there is little established methodology for designing and evaluating hybrid consensus approaches. Consequently, this work does not attempt to develop a fully fledged protocol with formal safety and liveness proofs. Instead, it focuses on observing system behavior under ideal conditions to determine whether a hybrid consensus approach is viable and has practical utility.

Regarding the system environment, this research assumes a fail-stop failure model without recovery from stable storage, thereby excluding the I/O overhead associated with durable logging. It does not address Byzantine faults, where malicious actors could intentionally circumvent the safety invariants of the consensus algorithms. Furthermore, the scope is restricted to software-level regulation at the consensus layer. It explicitly excludes hardware-based network optimizations or modifications to the underlying transport protocols.

Finally, this study is designed to isolate the overhead of the consensus mechanism. It does not account for complex application-level state machines, which could shift the overall performance bottleneck away from the network and the consensus protocol itself.
